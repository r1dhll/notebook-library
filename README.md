# Notebook library

A free library of NotebookLM notebooks for CBSE. A student opens one notebook and asks it. The answers come from the books and papers inside that notebook, not from the open internet.

The notebooks live on NotebookLM. This repo is the shelf: which class, which subject, and where the official books and papers are.

The textbooks are not in this repo. They stay on the official sites.

## Adding a subject

One folder. Same shape every time.

```
class-10/
  math/
    README.md
```

The first folder is the class. The folder under it is the subject. The README in that folder has four things:

1. Board, class, and subject.
2. The NotebookLM link, once the notebook is public.
3. What is inside, in one line.
4. Links to the official book and the official papers. Not the files.

Do not add the textbook PDFs. Do not invent a new shape.
